## 日志系统架构

### 日志数据库分类

| 数据库名称 | 路径 | 说明 |
|-----------|------|------|
| 告警日志 | log_db/alarm_log_db | 存储告警相关日志 |
| 通讯日志 | log_db/communicate_log_db | 存储设备通讯日志 |
| 设备参数日志 | log_db/device_param_log_db | 存储设备参数变化日志 |
| 运行日志 | log_db/operation_log_db | 存储操作运行日志 |

### 日志清理机制

系统实现了两种日志清理机制：
1. **月度清理** (month_clean.log): 定期检测并清理超过保留阈值的月份数据
2. **磁盘空间清理** (clean.log): 检测磁盘空间使用率，超过阈值时触发清理
