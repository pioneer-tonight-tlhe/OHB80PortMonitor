# CHANGELOG

## 2026-07-14

### Fixed

- 修正“曲线追加模式”复选框行为：勾选后 X 轴切换为累计秒数，取消勾选后恢复时分秒显示，曲线数据继续实时追加。
- 调整 ChartPage 布局顺序，将任务控制区和曲线选项区放在上方，曲线图放在页面最下方。
- 为任务控制区和曲线 CheckBox 区增加独立的浅色背景、边框和圆角样式。
- 为 PurgeTask 新增独立的 `scheduler/purge_task` 日志子目录，分别记录任务阶段摘要和指令通信明细。
- 指令日志新增完整请求帧、响应帧、JSON 参数、重试次数、通信耗时和失败原因。
- 精简 PurgeTask CSV 字段，移除阶段序号和 Idle Purge 状态字段，并在压力、流量、湿度、温度表头中标注单位。
- 将 ChartPage 曲线图 Y 轴最大值调整为 `100`。

## 2026-07-13

### Added

- 新增普通一次性充气调度任务，支持按配置顺序执行多个阶段和阶段动作。
- 新增 `purge_task.ini` 配置读取，默认设备为 `12001`，默认执行 30 秒 10 L/Min 和 570 秒 30 L/Min 两个阶段。
- 新增通用 CSV 文件写入工具，支持创建文件、写入表头和追加记录。
- 新增阶段独立 CSV 和全阶段 CSV 数据记录，按设备、日期和任务开始时间组织输出目录。
- ChartPage 新增 QRCode 选择、任务开始、任务结束、打开记录目录和任务完成提示。
- ChartPage 新增进气压力、出气压力、进气流量、相对湿度和温度五条实时曲线，每 100 ms 从共享设备数据刷新。
- 新增五条曲线的独立显隐复选框，以及用于暂停或恢复新增数据点的“曲线追加”复选框。
- 成功完成充气任务后自动保存当前曲线截图到任务记录目录。

### Changed

- 阶段计时仅在当前阶段所有必需动作下发成功后开始。
- 必需动作失败时立即终止当前阶段和整个充气任务。
- 阶段切换时不自动下发停止流量指令。
- 曲线区域增加浅色背景，并使用明显不同的颜色和线型区分各项设备数据。

### Documentation

- 新增充气任务数据类型、生命周期、失败边界、CSV 和 UI 协作设计稿。
